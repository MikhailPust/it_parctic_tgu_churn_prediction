# Комплект к занятию 3: разведочный анализ данных

Занятие: **17 октября 2026 года**. Сдача: **к началу занятия 24 октября 2026 года**.

Прочитайте `Задание_занятие_3.md` и `Вводная_от_заказчика.md`. Работайте со своими очищенными таблицами второго этапа. Новые файлы дополняют проект и не заменяют его историю.

| Файл | Назначение |
|---|---|
| data/network_quality_monthly.csv | Технические измерения по пяти регионам за сентябрь 2025 — август 2026 |
| data/business_context.csv | Календарь событий и сообщений компании для интерпретации графиков |
| data_dictionary_lesson3.csv | Поля, единицы наблюдения и ограничения новых источников |
| analysis_plan.csv | Пустой шаблон плана четырёх гипотез |
| starter/eda_start.ipynb | Начало ноутбука: загрузка таблиц и проверки; дальнейший анализ выполняет команда |
| Шаблон_отчёта_EDA.md | Структура итогового отчёта |

CSV: UTF-8 с BOM, разделитель `;`, десятичная точка. Время новых источников — ISO 8601 с явным смещением `+03:00`. Даты без времени в календаре событий — календарные даты Москвы; начало и конец описанного периода включены.

Распакуйте архив в `lesson3`. Для стартового ноутбука: Python 3.10+, pandas, matplotlib и Jupyter; установите их в виртуальную среду и зафиксируйте фактические версии. Откройте ноутбук из `lesson3/starter` и задайте путь `PREPARED` к своей папке результатов занятия 2. Используйте «Restart kernel → Run all» для проверки воспроизводимости.

Новые источники синтетические. Измерения сети сгенерированы отдельно, без использования будущих меток оттока. Связь качества сети и индивидуального ухода не гарантирована. Готового EDA и очищенных результатов второго этапа в студенческом комплекте нет.

Перед сдачей убедитесь, что для сравнения с оттоком используются только согласованные даты обучения. Не исследуйте связи признаков с исходами валидации и теста для выбора гипотез или будущих признаков.
