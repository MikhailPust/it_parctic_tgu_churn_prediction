# Комплект ко второму занятию

Занятие 10 октября 2026 года. Тема: сбор и подготовка данных. Дедлайн: к началу занятия 17 октября.

Сначала прочитайте «Задание_занятие_2.md». Распакуйте комплект первого занятия в отдельную папку lesson1, а этот комплект в lesson2. Сохраняйте исходники без изменений.

В data/ лежат новые обращения. support.sqlite содержит таблицу support_current_raw. support_current_export.csv повторяет ту же таблицу: выбирайте один путь чтения. Старый файл support_legacy_sep_oct_2025.csv нужен в обоих вариантах.

Пример запуска из родительской папки:

```bash
python lesson2/starter/extract_support.py --db lesson2/data/support.sqlite --output work/support_extracted.csv
```

Требования: Python 3.10 или новее. Для стартового примера дополнительных библиотек не требуется. Для собственной подготовки команда выбирает Pandas, Polars или другой подход и фиксирует версии зависимостей.

В schema_support.csv описано соответствие старых и новых полей. Формат старых дат локальный московский, новая система использует UTC; значения без часового пояса по подтверждению заказчика также относятся к Москве.

Биллинг, абоненты и события договора остаются из первого комплекта. Новые идентификаторы реальных абонентов не вводятся. Некоторые некорректные записи поддержки могут не связываться с реестром: исследуйте их и сохраните отдельно с причиной.

Готового решения в этом комплекте нет. На втором этапе не требуется обучение модели, подбор параметров или доказательство причин оттока.
