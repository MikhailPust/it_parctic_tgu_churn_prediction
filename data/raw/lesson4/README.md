# Комплект к занятию 4

Тема: **формирование признаков и выбор метода решения**. Занятие: **24 октября 2026**. Сдача: **к началу занятия 31 октября**.

Начните с `Вводная_от_заказчика.md` и `Задание_занятие_4.md`. Используйте собственные результаты этапов 2–3. Новые данные дополняют прежние источники.

| Файл | Назначение |
|---|---|
| data/digital_usage_monthly.csv | Месячная телеметрия личного кабинета |
| data_dictionary_lesson4.csv | Поля, состояния наблюдения и время доступности |
| feature_catalog_template.csv | Шаблон паспорта признаков |
| config_example.json | Пример дат, горизонта и активной базы |
| starter/features_start.ipynb | Загрузка, проверки входа и пример одного безопасного признака |
| starter/preprocessing_template.py | Преобразование чисел и категорий, fit только на train |
| Шаблон_плана_моделирования.md | Базовое правило, кандидаты и порядок оценки |

CSV: UTF-8 с BOM, разделитель `;`, десятичная точка. Даты времени — ISO 8601 с `+03:00`. Все данные синтетические.

Распакуйте комплект в `lesson4`. Стартовый ноутбук рассчитан на запуск из `lesson4/starter`; в нём нужно изменить `PREPARED` на путь к своим результатам второго этапа. Для ноутбука нужны Python 3.10+, pandas и Jupyter. Для примера преобразования нужен scikit-learn; фактические версии зафиксируйте в своём проекте. Скрипт шаблона использует только названия столбцов, переданные командой, и сам не выбирает признаки.

Стартовые материалы не строят готовый набор признаков или модель. Разделите ключи, признаки, метки и служебные поля. Значения, полученные только из будущего или из финального аудита, не должны незаметно попасть в матрицу X.
